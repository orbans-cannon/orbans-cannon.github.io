## 預計涵蓋

- **HotStuff 留下的缺口**：Pacemaker 負責 GST 之後的進展；Cogsworth 指出 HotStuff 把這個邏輯包成一個模組，沒有形式定義也沒有實作。
- **Cogsworth**：把 view synchronization 抽成獨立問題並形式化，給出樂觀線性通訊、常數延遲的演算法。注意它數的是 messages。
- **RareSync**：view synchronization 通訊 $O(n^2)$ words、延遲 $O(f\cdot\delta)$，配上與 HotStuff 相同的 view core 得到 SQuad，worst-case 通訊 $O(n^2)$ words；數的是 words，與 Cogsworth、HotStuff 的度量不同，預計逐條標明。
- **後續**：Lumiere（Lewis-Pye 等，PODC 2024）預計放一小段；這篇本站還沒有收入書目，也還沒讀，寫頁時再處理。
- **與下界的關係**：RareSync 讓 Dolev–Reischuk 的二次通訊下界在部分同步下追平，見 [通訊下界](/impossibility/cost/dolev-reischuk/)。
- **邊界**：各論文的複雜度度量（messages、words、authenticators）不能直接相減。
